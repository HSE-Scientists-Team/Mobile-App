## Ловушки Figma (для следующих правок)

- `use_figma` атомарен: при исключении все изменения скрипта откатываются.
- `findOne` не видит скрытые узлы внутри экземпляров; во свежем клоне кадра вложенные узлы App bar находятся, только если
  сначала обратиться к `children[1]`.
- Переход NAVIGATE нельзя ставить на тот же верхний кадр, на котором стоит источник.
- Правка главного компонента пересчитывает все экземпляры: пограничный перенос строки (281 против 280 px) может
  неожиданно сработать.
- Прозрачность заливки, привязанной к переменной цвета, сервис скриншотов не рисует; для «выключенного» — прозрачность слоя.
- Скриншот-сервис рисует главные компоненты на странице Design System с чёрным фоном карточек (в сырых заливках — чёрный
  при привязанной переменной); проверять по экземплярам на экранах и по числам.
- Тип easing «ease in-out» в Plugin API называется `EASE_IN_AND_OUT`.
- Если в экземпляре удалить родителя и перенести ребёнка в главном компоненте, ребёнок снова появляется в экземпляре;
  скрывать вручную.
