# Что реализовано и что нет: карта историй и дизайн

Снимок на 2026-10-21. Сверено с живой [User story map](https://www.figma.com/board/GsyCGZrgtygsBQpstgJ6tA/User-story-map) (стикеры 509–658) и с файлом
[Study Projects Networking](https://www.figma.com/design/ZuxIEEKYK8619rAb7bAtM6/Study-Projects-Networking) (страница «MatchLab App»: 127 кадров).

**«Реализовано»** — экран и действие есть в приложении и подключены к API (Gateway v2.6.0); логика покрыта host-тестами. Проверка на живом
сервере и на устройстве агентами не делается (запрет): то, что прогонял на эмуляторе заказчик (статусы проектов и откликов,
подтверждение достижений, фото аватара), заказчик видел сам; остальное на сервере не проверялось. iOS — только компиляция Kotlin.

## 3. Где реализация отличается от макета или шагнула дальше него

Решения заказчика и допущения (нужно показать дизайнеру):
- Карточка работы без стрелки справа (в Figma у `Card/Work` свойство `showChevron`).
- Аватары без фото — инициалы на синем круге; в Figma иллюстрации и `person=unknown`.
- Группа «Статус» в фильтрах людей убрана.
- Нет в макете, нарисовано из компонентов: смена фото на 10b; блок «Прикрепить файл» на 11/11b/12/12b; список, пусто и ошибка
  рекомендаций проектов на ленте; чекбокс «Отправлять статистику использования» на регистрации и переключатель на 18 (в работе).
- Кадра «14 Уведомления» нет вообще: push в API нет (G61/G70), точки и счётчики есть.
- Приложение: название MatchLab и иконка — по референсу заказчика, в наших цветах (`docs/brand`).

## 4. Не сделано и почему

| Что | Причина | Что нужно |
|---|---|---|
| Блокировка пользователей (541, строка в 18, «Заблокировать» в 09c/17) | клиент не делали; **API теперь есть** (`GET /users/me/blocks`, `PUT`/`DELETE /users/me/blocks/{id}`) | решение «берём» |
| Статус участника (G52) | `mine` сделан (G44, G67 закрыты); `ProjectMember.status` в приложении не читается: «вышедший участник не отображается» проверено заказчиком | не нужно |
| Push-уведомления (521, 537, 574) | в API их нет (G61, G70); приложение опрашивает чаты раз в 5 с | решение бэкенда |
| Поиск и рекомендации «на роль» (524, 525) | сервер роль не принимает (G31, G32) | бэкенд |
| «Документы и фото не показывать» (543) | настройки в API нет; в `UserPrivacySettings` только `show_contacts` и `show_participating_projects`, которых нет в макетах | решение продукта |
| Аналитика AppMetrica | в работе (агенты, `docs/contract-analytics.md`) | ключ приложения от заказчика |
| iOS | Xcode нет: компилируется только Kotlin; `iosApp/` агенты не правят: Universal Links, Swift-мост AppMetrica, иконка 1024 px, подпись под иконкой (`PRODUCT_NAME`) | за заказчиком |
| Ссылка из письма | нужны `assetlinks.json` и `apple-app-site-association` на сайте (`docs/backend-deeplinks.md`) | бэкенд |
| Поле тегов: действие клавиатуры (T2) | уже добавляет тег по «Готово»; заказчик не ответил, чего не хватает | ответ заказчика |
| Стори администратора (31) | админ-панель, не приложение | вне объёма |

## 5. Проверка

Последний полный прогон (до работы над аналитикой): host-тесты всех модулей, `:androidApp:assembleDebug`, компиляция iOS
(`iosSimulatorArm64`, `iosArm64`) — зелёные. Визуальная проверка на устройстве агентами не выполнялась. Значения, которые пишет
сервер, сверены с кодом бэкенда и его PR #16 (`docs/api-values.md`).
