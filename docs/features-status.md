## Что проверить первым

1. Формат дат проекта: приложение шлёт `YYYY-MM-DD` (начало — первое число месяца, конец — последнее).
2. Коды действий проекта: `2` снять с публикации, `3` начать, `4` завершить, `5` отменить.
3. «Я инициатор»: находит ли обход `GET /projects` ваши проекты, в том числе только что созданные.
4. Коды статусов проекта `1`–`5` и типа и статуса откликов: если сервер отдаёт другое, значения читаются как «неизвестно», и кнопки статусов не появятся.
5. Создание проекта без ролей: уходит `roles: []`; если сервер ответит 400, нужна проверка «хотя бы одна роль».
